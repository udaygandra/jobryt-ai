# Plan 10.1: Multi-Country Cities Dataset & Global Geo API

## Objective
Expand the location autocomplete and geocoding intelligence beyond Canada to comprehensively cover all 18+ countries supported in Settings (US, UK, Canada, Germany, Australia, France, India, Netherlands, UAE, Singapore, Japan, Brazil, Italy, Poland, South Africa, Austria, New Zealand, Mexico, and Global Remote). Build a high-performance dataset and REST API that serves country-specific or global city datasets with state/province, country code, and flag metadata.

## Context
- `scripts/core/geo-helper.js` (SUPPORTED_COUNTRIES and geo validation)
- `data/config/geo-hierarchy.json` (city and province hierarchies)
- `public/data/canada-cities.json` (existing single-country file to preserve backward compatibility)
- `src/routes/settings.js` (settings API routes)

         * region: "State / Province / Region" (optional)
         * country_code: "2-letter ISO"
         * country_name: "Country Name"
         * flag: "Country Emoji Flag"

    2. Maintain `public/data/canada-cities.json` as a backward-compatible subset so any existing client code continues to work seamlessly.
    3. Update `data/config/geo-hierarchy.json` with major international city mappings for all 18 countries so backend location filtering in `geo-helper.js` recognizes these global locations.

  <files>

  <action>
    1. In src/routes/settings.js:
       - Add route `GET /api/settings/cities`:
         * Accepts query param `?country={code}` (e.g., `?country=US`, `?country=IN`, `?country=DE`, `?country=ALL`).
         * If `country` is specified and matches a supported country, returns the curated cities and popular quick chips for that specific market.

    2. Create automated test `tests/test-cities-api.js`:
       - Tests `GET /api/settings/cities?country=CA` returns Canadian cities.

       - Tests `GET /api/settings/cities?country=IN` returns Indian tech hubs (Bengaluru, Hyderabad, Pune, etc.).
       - Tests `GET /api/settings/cities?country=DE` returns German cities (Berlin, Munich, Frankfurt, etc.).
       - Tests `GET /api/settings/cities?country=ALL` returns full global list.
  </action>
