# Plan 9.2: First-Time Onboarding Setup Wizard, Plain English Navigation, Skeleton Loaders & Light Theme Polish

## Objective
Transform the user experience for non-technical and international job seekers by re-labeling all menu navigation with simple, friendly English, replacing the workflow guide with an intuitive first-time setup wizard, eliminating jarring "0 results" flashes with shimmering skeleton loaders, and perfecting light mode so it looks as beautiful and cohesive as dark mode.

## Context
- Requirements 4, 5, 6, 7 from user prompt.
- `public/index.html`
- `public/js/navigation.js`
- `public/js/guide.js`
- `public/js/opportunities.js`
- `public/js/applied.js`
- `public/css/theme.css`
- `public/css/style.css`
