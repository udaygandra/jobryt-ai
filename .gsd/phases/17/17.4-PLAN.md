# Plan 17.4: Applications Page Card Space Optimization & Embedded Recruiter Intelligence

## Objective
Optimize the application card layout on the Applications page to eliminate awkward empty whitespace, provide a smart Google Search fallback for job postings lacking direct links, and embed a dedicated 1-click Recruiter Finder tool directly in each job application card.

## Context
- `public/js/applied.js`
- `src/routes/recruiters.js`
- `public/index.html`
- User uploaded screenshot showing empty space next to Stage selector & actions on application card

## Tasks

<task type="auto">
  <name>Add Job Posting Search Fallback & Embed Recruiter Finder Button</name>
  <files>
    public/js/applied.js
  </files>
  <action>
    - In `public/js/applied.js` card generator:
      - If `jobUrl` exists, render the external posting link button with tooltip "Open Posting".
      - If `jobUrl` is missing or empty, render a "Search Job on Google" link button (`https://www.google.com/search?q=${encodeURIComponent(app.title + ' ' + app.company + ' job')}`) with tooltip "Find posting on Google" so no space is wasted and users can locate the job with 1 click.
      - Add a prominent, styled `🤝 Find Recruiters` button in the action bar of every application card.
      - Ensure the card's right action zone is well-spaced, wrapping cleanly on mobile and filling available width on desktop without awkward voids.
  </action>
  <verify>
    node -e "const fs = require('fs'); const code = fs.readFileSync('public/js/applied.js', 'utf8'); assert(code.includes('Find Recruiters') || code.includes('recruiter')); console.log('✅ Recruiter button added to card');"
  </verify>
  <done>
    Every application card features a Find Recruiters action and a reliable posting link/search fallback.
  </done>
</task>

<task type="auto">
  <name>Build In-Card Recruiter Intelligence Drawer / Modal</name>
  <files>
    public/js/applied.js
    public/index.html
  </files>
  <action>
    - In `public/js/applied.js`:
      - Implement `openRecruiterFinder(jobId, company, city, title)`:
        - Fetches `GET /api/recruiters/search?company=${encodeURIComponent(company)}&city=${encodeURIComponent(city)}`.
        - Opens an interactive in-card drawer (or sleek modal `#recruiter-finder-modal`).
        - Displays:
          1. **Google X-Ray Recruiter Search**: Direct link to LinkedIn profiles for talent acquisition and technical recruiters at that company.
          2. **Google X-Ray Leadership Search**: Direct link to engineering managers, directors, and heads of department at that company.
          3. **LinkedIn Company Search**: Direct link to LinkedIn people search.
          4. **1-Click Copy Outreach Note**: Pre-drafted LinkedIn connection note (≤300 chars) tailored to the specific role and company, with a quick "Copy to Clipboard" button and toast feedback.
          5. Direct Google search for the job posting if missing.
  </action>
  <verify>
    node -c public/js/applied.js
  </verify>
  <done>
    Candidates can discover recruiters and copy customized outreach messages directly from any application card with 1 click.
  </done>
</task>

## Success Criteria
- [ ] No empty dead space in job application cards
- [ ] Jobs without direct links provide a 1-click Google search fallback
- [ ] Embedded "Find Recruiters" button generates real LinkedIn Google X-Ray searches and copyable notes
