# Plan 10.3: Comprehensive Tier 1, Tier 2 & Tier 3 Global Cities Dataset & Search API

## Objective
Expand the multi-country cities dataset to include comprehensive Tier 1 (major metropolises), Tier 2 (state/regional capitals & key economic centers), and Tier 3 (secondary industrial & emerging tech hubs) for all 18+ supported countries (US, GB, CA, DE, AU, FR, IN, NL, AE, SG, JP, BR, IT, PL, ZA, AT, NZ, MX, GLOBAL). Provide tiered metadata, fast API search/filter, and full geo-hierarchy matching so candidates can target any city at any tier.

## Context
- `scripts/build-global-cities.js` (dataset generator script)
- `public/data/global-cities.json` (bundled frontend dataset)
- `data/config/geo-hierarchy.json` (backend geo-matcher used by `geo-helper.js`)
- `src/routes/settings.js` (`GET /api/settings/cities` endpoint)
- `tests/test-cities-api.js` (integration verification test)
