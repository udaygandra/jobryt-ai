# Phase 32 Plan 2: Replace "Pass" with Permanent Delete (Purge from DB, Keep seen_jobs) Summary

**Replaced the "Pass" button with a two-click trash-can deletion button that completely purges unwanted opportunities from the database while maintaining deduplication memory in seen_jobs.**

## Accomplishments
1. **Backend Opportunity Purge (`scripts/core/jobs-db.js` & `src/routes/jobs.js`)**:
   - Added `purgeOpportunity(jobId)` executing within a SQLite transaction (`BEGIN` / `COMMIT` / `ROLLBACK`).
   - Gathers all id variants (clean, stripped prefix, pending table aliases).
   - Inserts all ids into `seen_jobs` (lowercased) so background scanner deduplication in `src/routes/pipeline.js` permanently suppresses the opportunity.
   - Deletes matching rows from `pending_jobs`, `rejected_jobs`, and unapplied rows from `tailored_resumes`.
   - Guaranteed immunity for `applied_jobs`: records already in My Applications are never deleted or modified.
   - Created `DELETE /api/jobs/pending/:id` which calls `purgeOpportunity` and deletes disk artifacts in `data/tailored/<id>/`.

2. **Frontend Inline Confirmation (`public/js/opportunities.js`)**:
   - Replaced "Pass" in the card action bar with an accessible `🗑️` button (`#btn-delete-${job.id}`).
   - Implemented `deleteOpportunity(jobId)`: click 1 transforms the button into a rose `Delete?` pill armed for 3 seconds. Click 2 sends the DELETE request, animates card removal, cleans local cache, and displays toast notification.
   - Preserved `rejectJob` for backward compatibility and exported `window.deleteOpportunity`.

## Verification
- Unit test verified that `purgeOpportunity` removes test jobs from `pending_jobs` and inserts them into `seen_jobs`.
- E2E HTTP server test verified that `DELETE /api/jobs/pending/:id` returns 200 and removes the pending job record.
- Protection test verified that jobs existing in `applied_jobs` are not deleted by `purgeOpportunity`.
- Unapplied `tailored_resumes` deletion verified.

## Deviations from Plan
None — plan executed exactly as written.
