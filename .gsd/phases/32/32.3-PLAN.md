# Plan 32.3: Light Theme Residual Dark Element Sweep (All Pages, Zero Dark-Theme Regression)

## Objective
Remove every element that stays dark in light theme, on all views (`#view-feed`, `#view-applied`, `#view-profile`,
`#view-config`, `#view-custom`, `#view-recruiters`, `#view-guide`) and in modals. The dark theme must stay pixel-identical, so
**every new rule is scoped under `[data-theme="light"]`** in `public/css/theme.css`. No dark-theme markup is changed.
