# Plan 14.1 Summary: Setup Wizard Dismissal & On-Demand Launch Engine

## Overview
Resolved the Setup Wizard auto-popup loop on page reload. The wizard now respects user dismissal (`dismissed` in `localStorage`), checks existing profile state (`target_titles`, `locations`, `contact`), and provides an on-demand "✨ Setup Wizard" button in the Settings page header for user control.

## Changes Completed
- **`public/js/guide.js`**:
  - Enhanced `checkFirstTimeOnboarding()` to check `localStorage['jobryt_onboarded']` for `'true'` and `'dismissed'`.

  - Added `skipWelcomeWizard()` to cleanly store `jobryt_onboarded = 'dismissed'` and display confirmation toast.
  - Updated `closeWelcomeWizard()` to persist dismissal if not previously completed.
- **`public/index.html`**:
  - Added `✨ Setup Wizard` action button to the Settings page header (`#view-config`).
  - Wired the "Skip for now" footer button to `skipWelcomeWizard()`.
