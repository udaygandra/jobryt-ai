# Plan 14.1: Setup Wizard Dismissal & On-Demand Launch Engine

## Objective
Fix the Setup Wizard auto-popup loop so it does not reappear on page reload once dismissed or when the user already has a configured profile, while adding an on-demand "✨ Setup Wizard" button in the Settings page header.

## Context
- `public/js/guide.js`
- `public/index.html`
- `public/js/app.js`

## Tasks

<task type="auto">
  <name>wizard-dismissal-and-profile-check</name>
  <files>public/js/guide.js</files>
  <action>
    - Update `checkFirstTimeOnboarding()` in `guide.js`:
      - If `localStorage.getItem('jobryt_onboarded')` is `'true'` or `'dismissed'`, do NOT open wizard.
      - Check if profile is already configured: if `window.currentProfile` has `target_titles?.length > 0` or `locations?.length > 0` or `contact?.name`, or if master profile exists on server, set `jobryt_onboarded` to `'true'` in localStorage and do not popup.
    - In `closeWelcomeWizard()`:
      - Set `localStorage.setItem('jobryt_onboarded', 'dismissed')` so clicking close persists across reloads.
    - Add `skipWelcomeWizard()` function wired to "Skip for now" button that sets `jobryt_onboarded = 'dismissed'` and closes modal with toast.
  </action>
  <verify>grep -n "dismissed" public/js/guide.js</verify>
  <done>Setup wizard respects dismissal and existing profile state; never pops up unexpectedly on reload.</done>
</task>

<task type="auto">
  <name>add-settings-wizard-button</name>
  <files>public/index.html</files>
  <action>
    - Add a "✨ Setup Wizard" button to `#view-config` header action bar in `public/index.html` alongside "Save Settings" and "Run Manual Scan".
    - Clicking the button calls `openWelcomeWizard()`.
    - Update "Skip for now" link/button in the wizard modal to call `skipWelcomeWizard()`.
  </action>
  <verify>grep -n "openWelcomeWizard" public/index.html</verify>
  <done>Settings page features an on-demand Setup Wizard launcher button.</done>
</task>

## Success Criteria
- [ ] Setup wizard only auto-displays on virgin state without prior dismissal or configured profile
- [ ] Users can launch the wizard anytime from the Settings page header
