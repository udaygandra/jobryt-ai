# Plan 14.2 Summary: Standardized City Formatting, Flag Detection & 5-City Guardrail

## Overview
Normalized geocoder results to uniform `City, ST, Country` format (e.g., `Redwood City, CA, USA` and `San Francisco, CA, USA`), enhanced flag recognition to reliably detect country flags, and enforced a maximum quota of 5 target cities across the app to safeguard free-tier scoring quotas.

## Changes Completed
- **`scripts/core/geo-helper.js`**:
  - In `searchLiveCities()`: Mapped US state names to 2-letter postal codes (e.g. `California` -> `CA`), mapped Canadian provinces to 2-letter codes, and normalized country name `United States` -> `USA`.
  - Output format is now consistently `City, ST, Country` (e.g. `Redwood City, CA, USA`).
- **`public/js/settings.js`**:
  - Implemented `MAX_LOCATIONS = 5`.
  - Updated `addLocationTag()` to reject additions exceeding 5 cities with a warning toast.
  - Enhanced `detectLocationFlag()` with full regex support for US state postal codes and full names, ensuring 🇺🇸 flag is accurately displayed for any US city.
  - Updated `renderLocationTags()` to display live slot count `(${locCount}/${MAX_LOCATIONS})`.
- **`public/index.html`**:
  - Added `#settings-cities-count-label` to the Step 2 Target Cities label.
- **`public/js/guide.js`**:
  - Enforced the 5-city limit in `addWizardLocation()`.

## Verification
- Verified `searchLiveCities('Redwood City', 'US')` returns `{ city: 'Redwood City', region: 'CA', country: 'USA', formatted: 'Redwood City, CA, USA' }`.
- Verified 5-city quota blocks additional insertions and shows warning toast.
