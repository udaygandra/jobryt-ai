# Plan 15.3: Resume & Profile Section Full-Width ATS Editor & Modal Format JSON

## Objective
Transform the Resume & Profile section from a cramped half-screen layout into a full-width, professional ATS-grade candidate editor, remove the permanently displayed raw JSON textarea in favor of an on-demand "Format / View JSON" modal for technical users, and provide complete flexibility to add, edit, or remove any section, experience, project, education, or skill tag.

## Context
- `public/index.html`
- `public/js/profile.js`
- `src/routes/profile.js`

## Tasks

<task type="auto">
  <name>remove-permanent-json-and-add-modal</name>
  <files>public/index.html, public/js/profile.js</files>
  <action>
    - Remove the permanent right-column `textarea id="prof-json"` from `#view-profile`.
    - Change layout from 2-column split (`grid-cols-1 lg:grid-cols-2`) to a spacious full-width container (`max-w-5xl mx-auto space-y-6`).
    - Add an on-demand modal/drawer for "Format JSON":
      - Triggered by button `⚙️ View / Edit JSON` in the profile action bar.
      - Modal contains formatted JSON editor with syntax formatting and "Save JSON" sync.
    - Default view is 100% focused on candidate forms and cards without confusing non-technical users.
  </action>
  <verify>grep -n "prof-json-modal" public/index.html</verify>
  <done>Raw JSON is hidden behind an on-demand modal; profile editor takes full width of the screen.</done>
</task>

<task type="auto">
  <name>ats-grade-modular-profile-editor</name>
  <files>public/index.html, public/js/profile.js</files>
  <action>
    - Upgrade profile sections with full CRUD flexibility:
      - Personal & Contact Info: clean responsive grid with phone, email, location, LinkedIn, GitHub, portfolio.
      - Professional Summary: generous textarea with character/word counter.
      - Target Roles & Locations: interactive multi-tag input with quick removal.
      - Core Skills: interactive tag chips with "+ Add Skill" inline input and category organization.
      - Work Experience: expand cards with role, company, dates, location, project, client name, and rich bullet points with bullet-level add/remove.
      - Projects: name, description, live link/repo, technologies tag input.
      - Education: degree, institution, graduation year, location, honors.
      - Certifications: name, issuing organization, issue year, credential ID.
    - Ensure `syncFormToJson()` and `saveMasterProfile()` capture all fields accurately and sync bidirectionally.
  </action>
  <verify>grep -n "removeExperienceCard" public/js/profile.js</verify>
  <done>Candidate master profile supports full modification, addition, and removal across all sections.</done>
</task>

## Success Criteria
- [ ] No raw JSON textarea visible by default; accessible via "View / Edit JSON" modal
- [ ] Resume & Profile page uses full width with clean, ATS-inspired card layout
- [ ] Users can edit, add, or delete any experience, project, skill, education, or certification
