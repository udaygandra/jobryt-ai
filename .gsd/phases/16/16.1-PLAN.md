# Plan 16.1: Profile Decluttering & Workday-Style Unified Skills Tag Manager

## Objective
Remove redundant "Target Country Job Sources" card from My Resume & Profile (since users already configure and view active sources in Settings), and replace the fragmented, confusing skills fields (verified skills textarea, secondary input, and domain category previews) with a single, large Workday-style skills section featuring interactive chips, fast add/delete, and paste support.

## Context
- `public/index.html`
- `public/js/profile.js`
- `src/routes/profile.js`
- `.gsd/ROADMAP.md`

## Tasks

  <files>public/index.html, public/js/profile.js</files>

    - Keep job board sources strictly in the Settings tab where they belong.

<task type="auto">
  <name>Implement Workday-Style Unified Skills Tag Manager</name>
  <files>public/index.html, public/js/profile.js</files>
  <action>
    - Replace `#prof-skills`, `#prof-skills-familiar`, and `#prof-categorized-container` in `public/index.html` with a unified Workday-style skills manager:
      * Section title: "Skills" (with dynamic count badge, e.g. "42 skills").
      * Helper text: "Add and manage technical and domain skills used to match jobs and tailor resumes."
      * An inline add form: text input `#prof-skill-input` + "+ Add" button `#btn-add-prof-skill`.
      * Large chip container `#prof-skills-tag-container` rendering removable badge chips with clean `×` remove buttons.
    - In `public/js/profile.js`:
      * Maintain `window.profileSkillsList` array initialized from `prof.skills`.
      * Add functions `renderProfileSkillsTags()`, `addProfileSkill(skillName)`, `removeProfileSkill(index)`.
      * Support pressing Enter in `#prof-skill-input`, comma-separated pasting (splits and adds multiple skills cleanly), and duplicate prevention (case-insensitive).
      * Wire `syncFormToJson()` and `collectProfileFromForm()` to pull skills directly from `window.profileSkillsList`.
  </action>
  <verify>node -c public/js/profile.js</verify>
  <done>Skills appear as clean interactive tags in one consolidated section matching Workday UX with seamless add and delete.</done>
</task>

## Success Criteria
- [ ] No "Target Country Job Sources" card appears in My Resume & Profile.
- [ ] Fragmented skill textareas and category boxes are replaced by one clean Workday-style tag container.
- [ ] Adding, deleting, and pasting skills works fluidly and syncs with profile state and JSON schema.
