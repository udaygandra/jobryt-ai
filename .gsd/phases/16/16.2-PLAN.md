# Plan 16.2: Clean Decimal Experience Stepper (0.5 Rounding Engine) & Contact Fields Standard Check

## Objective
Eliminate messy text strings like "around 5 years of experience" in favor of a crisp decimal experience editor constrained to 0.5 intervals (1, 1.5, 2, 2.5, etc.) with specific rounding rules (2.25 rounds to 2, 2.3 rounds to 2.5). Audit candidate contact and personal details against standard ATS expectations (Workday, Greenhouse, Lever) to keep only universally requested fields.

## Context
- `public/index.html`
- `public/js/profile.js`
- `public/js/utils.js`
- `.gsd/ROADMAP.md`

## Tasks

<task type="auto">
  <name>Build Decimal Experience Stepper UI & 0.5 Rounding Engine</name>
  <files>public/index.html, public/js/profile.js</files>
  <action>
    - Replace the unstructured `#prof-total-exp` text input with a dedicated decimal stepper component:
      * Decrement button (`-`) stepping down by 0.5 (min 0).
      * Number input `#prof-total-exp` (`step="0.5" min="0" max="50"`).
      * Increment button (`+`) stepping up by 0.5.
      * Unit label "Years".
    - Implement exact rounding logic function `roundExperienceYears(val)` in `public/js/profile.js` (or `utils.js`):
      * Parse numeric value.
      * Base = Math.floor(num), decimal = num - base.
      * If decimal <= 0.25 -> base (e.g. 2.25 -> 2.0).
      * If decimal > 0.25 and <= 0.75 -> base + 0.5 (e.g. 2.3 -> 2.5, 2.75 -> 2.5).
      * If decimal > 0.75 -> base + 1.0 (e.g. 2.8 -> 3.0).
    - On input blur/change, format and round value to nearest 0.5 step.
    - When loading profile, parse legacy strings (e.g. "around 5 years of experience", "8+ years") and initialize the input with the rounded number.
    - Synchronize with the profile header badge `#prof-exp-badge` so it displays e.g. "5 Yrs Exp" or "2.5 Yrs Exp".
  </action>
  <verify>node -e "function r(v){const n=parseFloat(v);if(isNaN(n)||n<0)return 0;const b=Math.floor(n),d=n-b;if(d<=0.25)return b;if(d<=0.75)return b+0.5;return b+1;} console.assert(r(2.25)===2, '2.25 failed'); console.assert(r(2.3)===2.5, '2.3 failed'); console.assert(r(2.75)===2.5, '2.75 failed'); console.assert(r(2.8)===3, '2.8 failed'); console.log('Rounding assertions passed');"</verify>
  <done>User can only set/store whole or 0.5 decimal numbers for experience, with 2.25 rounding to 2 and 2.3 rounding to 2.5.</done>
</task>
