# Plan 25.4: Search Query Dispatch, Post-Filtering, Prompt C Re-Ranker & Profile Integration

## Objective
Build the final query execution layer that converts validated titles into targeted job board API calls, implements post-filtering (fuzzy title similarity, exclude keywords), adds optional Prompt C hiring manager reranking, and integrates the complete pipeline into the UI and REST API.

## Context
- .gsd/SPEC.md
- scripts/engine/board-requests.js
- scripts/engine/market-validator.js
- src/routes/profile.js
- public/js/profile.js

## Tasks

<task type="auto">
  <name>Build per-title query generator and post-filtering engine</name>
  <files>scripts/engine/title-query-builder.js</files>
  <action>
    - Create `scripts/engine/title-query-builder.js`:
      - `buildValidatedQueries(validatedTitles, locationOptions)`:
        - Creates board-tailored queries for Adzuna (`title_only=title`, `what_exclude=exclude_keywords`), LinkedIn, Job Bank, etc.
        - Keeps search query strings short and structured; never sends raw paragraphs or resumes.
      - `postFilterPostings(postings, validatedTitles, options)`:
        - 1. Title similarity: fuzzy token ratio $\ge 0.7$ against title or primary synonym.
        - 2. Keyword exclusion: drops postings containing any `exclude_keywords` in title or primary description header.
        - 3. Deduplication: deduplicates by `(company, normalized_title, location)`.
  </action>
  <verify>node -e "const { buildValidatedQueries } = require('./scripts/engine/title-query-builder'); console.log(typeof buildValidatedQueries);"</verify>
  <done>`title-query-builder.js` generates clean board requests and post-filters postings.</done>
</task>

    - Create `prompts/job-rerank-eval.txt` (Prompt C):
      - System Prompt: Strict hiring manager persona judging fit (`strong | moderate | weak`, `matched`, `missing`, `one_line_reason`).
      - User Prompt: Accepts candidate profile and top 30 candidate postings trimmed to title, company, requirements.
    - Create `scripts/engine/job-reranker.js`:
      - `rerankPostings(profile, postings, options)`:
        - Computes embedding/cosine similarity ranking or invokes Prompt C if LLM is enabled and configured.
        - Attaches `hiring_manager_eval` metadata to job cards.
  </action>
