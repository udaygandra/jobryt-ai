<task type="auto">
  <name>Implement composite ranking formula, overlap deduplication, and tier-mix enforcement</name>
  <files>scripts/engine/market-validator.js</files>
  <action>
    - Extend `scripts/engine/market-validator.js` with `rankAndFilterTitles(probedCandidates, candidateLevel, options)`:
      - Pruning rules:
        - Drop or demote if `total_results < 15`.
        - Drop if `title_match_rate < 0.5`.
        - Deduplicate overlapping titles: if two queries yield > 70% common job IDs or fuzzy token overlap, merge into the one with higher fit score.
      - Composite ranking formula:
        $$\text{score} = 0.50 \times \text{fit\_score\_norm} + 0.20 \times \frac{\log_{10}(\text{total\_results}+1)}{\log_{10}(\text{max\_results}+1)} + 0.15 \times \text{seniority\_match} + 0.10 \times \text{title\_match\_rate} + 0.05 \times \text{recency\_score}$$
        where `seniority_match` is 1.0 for exact level, 0.6 for one-level-up stretch, and 0 otherwise.
      - Tier mix enforcement:
        - Select top 5 to 10 titles.
        - Ensure at least 3 `core`, at most 2 `stretch`, and at least 1 `adjacent`.
      - Feedback loop: if fewer than 5 titles survive validation, return retry payload with low-volume title list for feedback re-query.
  </action>
  <verify>node -e "const { rankAndFilterTitles } = require('./scripts/engine/market-validator'); console.log(typeof rankAndFilterTitles);"</verify>
  <done>Composite formula ranks validated titles and enforces tier-mix guardrails.</done>
</task>
