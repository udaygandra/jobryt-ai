# Plan 25.2: 15-Candidate Title Generation Engine (Prompt B) with Tiers, Evidence & Guardrails

## Objective
Implement Stage 3 of the pipeline: Prompt B and the Market Title Generator. Uses a 4-expert reasoning panel to propose exactly 15 candidate job titles classified into `core`, `adjacent`, and `stretch` tiers with explicit resume evidence, synonyms, and search keywords.

## Context
- .gsd/SPEC.md
- prompts/candidate-profile-extraction.txt
- scripts/engine/llm-provider.js
- scripts/engine/board-requests.js

## Tasks

<task type="auto">
  <name>Author Prompt B template with 4-expert panel and strict hard rules</name>
  <files>prompts/job-title-generation.txt</files>
  <action>
    - Create `prompts/job-title-generation.txt`:
      - System Prompt: 4-expert panel (Senior Technical Recruiter in local market, Principal Data Engineer, Product Owner / Functional Analyst, Hiring Manager).
      - Hard Rules:
        1. Real posted titles only (exact phrasing employers use in local market).
        2. No seniority inflation (calibrated to `current_level`, max 1 title one-level up labeled "stretch").
        3. No duplicates by synonym (e.g. "BI Analyst" and "Business Intelligence Analyst" consolidated with one in synonyms).
        4. Evidence required (every title must cite 2–4 specific profile facts).
        5. Honest gaps (likely missing skills listed).
        6. Location-aware (regional conventions, dominant local employer clusters).
        7. Diversity across tiers: `core` (3–4), `adjacent` (3–4), `stretch` (1–2).
        8. Exactly 15 candidate titles output.
        9. No protected attribute usage.
        10. Anti-injection delimiter compliance.
      - User Prompt: Accepts location, radius, remote preference, work type, user preferences, and Candidate Profile JSON.
      - Output schema: `market_notes` and `candidates` array with `title`, `synonyms` (max 4), `tier`, `seniority_target`, `fit_score` (0-100), `evidence`, `likely_requirements_missing`, `must_have_keywords`, `exclude_keywords`, `target_industries`, `why_this_location`.
  </action>
  <verify>node -e "const fs = require('fs'); const p = fs.readFileSync('prompts/job-title-generation.txt', 'utf8'); if (!p.includes('4-expert') && !p.includes('panel')) process.exit(1);"</verify>
  <done>Prompt B contains the complete 4-expert panel instructions, hard rules, and output schema.</done>
</task>

<task type="auto">

  <files>scripts/engine/market-title-generator.js</files>
  <action>
    - Build `scripts/engine/market-title-generator.js`:
      - `generateCandidateTitles(profile, options)`:
        - Assembles Prompt B variables (`city`, `region`, `country`, `radius_km`, `remote_pref`, `employment_types`, `user_prefs`, `profile_json`).
        - Calls LLM with temperature 0.4 and JSON mode enabled.
        - Validates JSON output: checks for 15 candidate objects, validates required fields, enforces tier values (`core`, `adjacent`, `stretch`), and verifies evidence array presence.
        - If schema check fails, performs 1 self-correcting retry.
        - Deduplicates titles by synonym cross-referencing.
        - Implements caching by `hash(profile_json + location)`.
        - Provides deterministic fallback title generator for offline/air-gapped operation.
  </action>
