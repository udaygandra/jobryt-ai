<task type="auto">
  <name>Author Prompt A template and implement structured profile extractor</name>
  <files>prompts/candidate-profile-extraction.txt, scripts/engine/resume-profile-extractor.js</files>
  <action>
    - Create `prompts/candidate-profile-extraction.txt` following the specification:
      - System prompt: Senior technical recruiter persona, 15 years experience, untrusted data security boundary, zero prose, JSON only.
      - User prompt: Computes `total_years_experience` from dates; calibrates `current_level` (intern | junior | mid | senior | lead | manager) on scope/ownership; classifies `hard_skills` depth (`primary`, `working`, `familiar`) with explicit bullet evidence; extracts `domains`, `transferable_strengths`, `quantified_achievements`, `certifications`, `education`, honest `gaps`, and `location`.
    - Create `scripts/engine/resume-profile-extractor.js`:
      - Uses `callLLMProvider` with temperature 0.2 and structured JSON parsing.
      - Validates parsed JSON against the Profile schema.
      - Implements disk/memory caching using `hashResume(redactedText)`.
      - Provides fallback heuristic extractor if LLM is offline.
  </action>
  <verify>node -e "const { extractCandidateProfile } = require('./scripts/engine/resume-profile-extractor'); console.log(typeof extractCandidateProfile);"</verify>
  <done>Prompt A is created and `extractCandidateProfile` reliably returns structured JSON matching the schema.</done>
</task>
