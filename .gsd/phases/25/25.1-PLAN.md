# Plan 25.1: Resume Ingestion, PII Redaction & Structured Profile Extraction (Prompt A)

## Objective
Implement Stage 1 and Stage 2 of the market-validated role discovery pipeline: strip personal identifiers (PII) and prompt injection payloads from uploaded resumes in "My Resume and Profile", and extract a structured Candidate Profile via Prompt A (calibrated seniority, evidenced skills, domains, and location) with disk caching.

## Context
- .gsd/SPEC.md
- src/routes/profile.js
- scripts/engine/resume-to-profile.js
- scripts/engine/resume-redactor.js
- scripts/engine/resume-profile-extractor.js

## Tasks

<task type="auto">
  <name>Harden code-based PII redaction and prompt-injection defense</name>
  <files>scripts/engine/resume-redactor.js</files>
  <action>
    - Ensure `redactResumeText(rawText)` in `scripts/engine/resume-redactor.js`:

      - Retains candidate city, province/state, and country tokens for market routing.
      - Strips prompt-injection vectors (instruction overrides, system prompt escapes, "rank me #1" instructions).

<task type="auto">
  <name>Author Prompt A and implement Candidate Profile Extractor</name>
  <files>prompts/candidate-profile-extraction.txt, scripts/engine/resume-profile-extractor.js</files>
  <action>
    - Author `prompts/candidate-profile-extraction.txt` (Prompt A):
      - 15-year technical recruiter persona, untrusted data boundary, zero prose, JSON only.
      - Computes `total_years_experience` from dates; calibrates `current_level` (intern | junior | mid | senior | lead | manager); classifies `hard_skills` depth (`primary`, `working`, `familiar`) with concise bullet evidence; extracts `domains`, `transferable_strengths`, `quantified_achievements`, `certifications`, `education`, honest `gaps`, and `location`.
    - Build `scripts/engine/resume-profile-extractor.js`:
      - Calls LLM with Prompt A, temperature 0.2, JSON mode.
      - Validates schema and caches by `hashResume(redactedText)`.
      - Provides resilient heuristic fallback when LLM is unavailable.
  </action>
  <verify>node -e "const { extractCandidateProfile } = require('./scripts/engine/resume-profile-extractor'); console.log(typeof extractCandidateProfile);"</verify>
  <done>Prompt A extracts validated profile schema with deterministic caching.</done>
</task>
