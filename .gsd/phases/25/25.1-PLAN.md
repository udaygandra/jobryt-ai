# Plan 25.1: Unified Resume-to-Profile & Market Target Roles Prompt Engineering

## Objective
Upgrade the existing `prompts/resume-parser.txt` and `scripts/engine/resume-to-profile.js` to parse raw resume text/PDF into all Master Profile UI fields while simultaneously identifying up to 10 accurate, market-validated target roles, standardized location, and country scope in a single high-precision LLM call.

  <files>prompts/resume-parser.txt</files>
  <action>
    - Update `prompts/resume-parser.txt`:
      - Integrate market-calibrated recruiter reasoning directly into the parser instructions:

        - Include `country_code` field (e.g. "CA", "US", "GB", "IN", "AU", "DE").

        - Preserve all existing critical rules: zero fabrication, no-loss bullet points, client fidelity, standardized location formatting.
