# Plan 13.1: Live Geocoding API Service & Backend Country-Scoped City Search Endpoint

## Objective
Implement a high-performance backend geocoding endpoint (`GET /api/settings/cities/live-search`) that interfaces with global edge geocoding APIs (Open-Meteo Geocoding), strictly restricts results to the target country, caches responses for sub-millisecond retrieval, and gracefully falls back to local city datasets if offline.

- [public/data/global-cities.json](file:///c:/Users/udays/Documents/jobryt-ai/public/data/global-cities.json)

## Tasks

<task type="auto">
  <name>Implement Live Geocoding Service with Country Scoping & Caching</name>
  <files>scripts/core/geo-helper.js, src/routes/settings.js</files>
  <action>
    1. In `scripts/core/geo-helper.js`:
       - Implement `searchLiveCities(query, countryCode)`:
         - Query Open-Meteo Geocoding API (`https://geocoding-api.open-meteo.com/v1/search?name={q}&count=15&language=en&format=json`) with a 2.5s abort timeout.
         - Filter results strictly by `c.country_code.toUpperCase() === countryCode.toUpperCase()` (or allow US and CA if scope is `US_CA`, all if `GLOBAL`).
         - Normalize results into structured objects:
           `{ city: r.name, region: r.admin1 || '', country: r.country || '', country_code: r.country_code, formatted: "${r.name}, ${r.admin1 ? r.admin1 + ', ' : ''}${r.country}", source: 'live_geocoding' }`.
         - Maintain an in-memory LRU/TTL cache (1 hour) keyed by `${countryCode}:${query.toLowerCase().trim()}` to deliver instant <2ms responses for repeated queries.
         - Gracefully catch network errors or timeouts and return local dataset matches without crashing.
    2. In `src/routes/settings.js`:
       - Register route `GET /api/settings/cities/live-search`:
         - Accept `q` (query string) and `country` (country code ISO-2).
         - Validate input: if query length < 2, return empty array.
         - Merge live geocoding results with any high-tier local matches from `public/data/global-cities.json`.
         - Deduplicate by normalized city name and region.
         - Return JSON: `{ success: true, country, query, cities: [...] }`.
  </action>

## Success Criteria
- [ ] `GET /api/settings/cities/live-search?q=markham&country=CA` returns Markham, Ontario, Canada with `country_code: 'CA'`.
- [ ] Non-Canadian cities (e.g., Markham, Illinois) are strictly filtered out when `country=CA`.
- [ ] Responses are cached in memory for sub-millisecond retrieval on repeat queries.
