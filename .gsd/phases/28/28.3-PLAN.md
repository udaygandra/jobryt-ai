# Plan 28.3: Uncapped High-Performance Concurrent Ingestion & Non-Blocking Scoring Engine

## Objective
Remove artificial hardlimits on job ingestion and scoring, and upgrade pipeline execution with high-throughput, non-blocking concurrent asynchronous processing:
1. Eliminate the arbitrary 30-job cap (`MAX_TO_SCORE = Math.min(unSeenJobs.length, 30)`) in `src/routes/pipeline.js` so all fresh, unseen opportunities are evaluated.
2. Replace serial `for...of` LLM scoring loops with a concurrent worker pool (e.g. 6-10 parallel scoring workers) with fast timeouts and automatic mathematical heuristic fallback so processing is instantaneous without blocking the event loop or node process.
3. Remove arbitrary slicing caps across board parsers in `fetch-all-boards.js`, maintaining rate limits and backoff only where external endpoints enforce them (e.g. LinkedIn 2 concurrent/150ms gap).

## Context
- `src/routes/pipeline.js` (lines 100-146: `MAX_TO_SCORE` and sequential `for (const job of jobsToScore)` loop)
- `scripts/engine/fetch-all-boards.js` (board parsers and result collection)
- `scripts/engine/fetch-pool.js` (`runPool` concurrent task runner)
- `scripts/engine/node-logic.js` (`computeHeuristicScore`, `runParseScore`)
