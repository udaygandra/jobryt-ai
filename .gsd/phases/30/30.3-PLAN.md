# Plan 30.3: Guided Post-Reset Onboarding Workflow & Automated End-to-End Test Suite

## Objective
Design and implement an intuitive guided post-reset user workflow so users are never disoriented or stranded after executing a factory reset, and author a comprehensive automated test suite covering full reset erasure, post-reset settings saving, and pre-scan validation scenarios.

## Context
- `public/js/settings.js`
- `public/js/guide.js`
- `public/index.html`
- `tests/test-fresh-reset-and-scan-validation.test.js`

  <files>tests/test-fresh-reset-and-scan-validation.test.js</files>
  <action>
    - Create `tests/test-fresh-reset-and-scan-validation.test.js`:
      * Test 1: Full Reset wipes `master-profile.json` (empty name/skills/role), unlinks uploaded resumes in `data/profiles/`, clears `jobs.db`/`seen_jobs.json`/`last_scan_result.json`, and resets `settings.json` without launching a background scan.
