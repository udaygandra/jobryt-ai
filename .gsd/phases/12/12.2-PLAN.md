# Plan 12.2: Instant Zero-Flicker Cold Start, Tab State Persistence & SWR Job Cache Hydration

## Objective
Eliminate the "no data displayed while UI is loading" experience on first load and page reload. Pre-render instant high-fidelity skeleton cards in static HTML, persist job feed data in SWR localStorage cache so jobs appear instantly in 0ms, persist the user's active tab so reloads never lose context, and present a polished First-Run Quickstart Hero on cold databases.
