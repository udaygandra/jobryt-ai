# Plan 29.2: Opportunities Header Redesign, Dynamic Logs/Insights Button & Live Scan Modal with Abort Controller

## Objective
Overhaul the Opportunities header to eliminate the confusing duplicate "Scan Feeds" button, replace it with a dynamic "Scan Insights & Logs" button (with live pulsing state when scanning), connect the global "Run Scan" button to the scan mutex, and build a rich Scan Diagnostics Modal with live progress logs, board-by-board yield cards, and an interactive "Stop Scan" button.

## Context
- `public/index.html`
- `public/js/opportunities.js`
- `public/css/components.css`
- `src/routes/pipeline.js`

## Tasks

  <action>

<task type="auto">
  <name>Build Live Scan Diagnostics Modal with Stop Controller & Board Yield Breakdown</name>
  <files>public/index.html, public/js/opportunities.js</files>
  <action>
    - Overhaul `#scan-modal` in `public/index.html`:
      * Header: "Job Pipeline Discovery Scan" with live status badge (`Live Scanning`, `Completed`, `Aborted`).
      * Step Stepper:
        1. Ingesting Boards -> 2. Freshness & Geo Filter -> 3. AI Scoring -> 4. Complete.
      * Action Buttons:
        - Prominent **"Stop Scan"** button `#btn-stop-scan` (visible when scanning is running) styled with danger/amber accent.

      * Board Yield Breakdown Grid (`#scan-board-breakdown`):
        - Visual cards showing listing counts fetched per board (e.g., Adzuna, Canada Job Bank, LinkedIn, ArbeitNow, Himalayas, Naukri, USAJobs).

        - Auto-scrolling terminal window displaying timestamped, color-coded log lines.

        - Total Fetched -> Filtered -> Deduplicated -> Scored -> Qualified Added.
    - In `public/js/opportunities.js`:
      * `openScanModal()`: Opens modal and immediately calls `/api/pipeline/status` to populate live or last scan state.
      * `stopScan()`: Sends `POST /api/pipeline/stop`, shows confirmation toast "Stopping scan...", and updates UI to aborted state.
      * `triggerPipelineScan()`: Handles HTTP 409 seamlessly by attaching to existing scan rather than erroring out.
      * Starts polling `/api/pipeline/status` while running, updating logs and stepper dynamically until completion.
  </action>
