# Plan 29.2 Summary: Opportunities Header Redesign, Dynamic Logs/Insights Button & Live Scan Modal with Abort Controller

## Overview
Replaced the confusing duplicate "Scan Feeds" button with a dynamic "Scan Insights & Logs" button with live status awareness, overhauled the Discovery Scan modal into an interactive diagnostic dashboard with a 4-stage funnel stepper, per-board ingestion cards, auto-scrolling terminal logs, and a dedicated mid-flight "Stop Scan" button.

## Key Changes
1. **Opportunities Header Redesign**:
   - Removed the duplicate "Scan Feeds" button in `public/index.html`.
   - Added `#btn-scan-insights` featuring live status indicator `#scan-status-dot` (pulses amber during active scanning, solid emerald when idle) and `#scan-insights-btn-text`.
   - Bound to `openScanModal()` so users can review the last scan results at any time, or monitor live progress if a scan is running.

2. **Discovery Scan Diagnostics Modal (`#scan-modal`)**:
   - Modernized modal header with live status badge (`Scanning Live`, `Idle / Ready`, or `Stopped`).
   - Added 4-stage stepper visualization (`1. Ingest`, `2. Filter`, `3. Score`, `4. Yield`).
   - Integrated `#scan-board-breakdown` grid displaying real-time listing counts per job board adapter.
   - Integrated auto-scrolling terminal log viewer `#scan-logs` with color-coded info, warning, and success diagnostics.
   - Added `#btn-stop-scan` button that calls `POST /api/pipeline/stop` to safely halt in-flight scans.

3. **Client-Side Polling & Mutex Handshake in `public/js/opportunities.js`**:
   - Implemented `openScanModal()`, `closeScanModal()`, and `stopScan()`.
   - Implemented `checkScanStatus()` with dynamic interval polling while a scan is running (`data.status === 'running'`).
   - Implemented `renderScanDiagnostics()` to hydrate all modal and navbar controls from live or persisted scan results.
   - Updated `triggerPipelineScan()` to catch HTTP 409 (`already_running`) and attach directly to the active scan stream rather than throwing an error or starting a duplicate run.
