# Plan 26.1: Universal Zero-Hardcoding Audit & Purge

## Objective
Purge all hardcoded locations, countries, timezones, and role assumptions across the codebase (`'Toronto'`, `'Canada'`, `'CA'`, `'America/Toronto'`, `'Data Analyst'`) so the application operates seamlessly for any candidate worldwide with any skillset.

## Context
- scripts/core/settings-helper.js
- scripts/core/geo-helper.js
- scripts/engine/fetch-all-boards.js
- public/js/settings.js
- public/js/profile.js
- data/config/settings.json

## Tasks
