# Plan 27.2: Setup Wizard Upload State Management & Disabled "Next" Button Guardrails

## Objective
Prevent premature progression in the Quick Setup & Welcome Wizard while a resume upload is being analyzed and parsed. Disable the "Next" button, display a clear "Please wait" indicator with an animated spinner, and only unlock progression once parsing is finished.

## Context
- `public/js/guide.js`
- `public/index.html`
- `public/js/profile.js`

## Tasks

<task type="auto">
  <name>Implement wizard upload state controller and disable Next button during parsing</name>
  <files>public/js/guide.js, public/js/profile.js</files>
  <action>
    - In `public/js/guide.js`:
      - Add `isWizardParsingResume` boolean state flag.
      - In `triggerResumeUploadFromWizard()`:
        * When file is selected, set `isWizardParsingResume = true`.
        * Disable `#wizard-btn-next`: set `disabled = true`, apply styling `opacity-50 cursor-not-allowed pointer-events-none`.
        * Update `#wizard-resume-status` to display an animated spinner and text: `⏳ Please wait, analyzing & parsing resume...`.
        * Disable the upload trigger button to prevent duplicate clicks.
      - Add `onWizardResumeParsed(success, data, error)` callback:
        * Reset `isWizardParsingResume = false`.
        * Re-enable `#wizard-btn-next` (remove disabled/opacity classes).
        * Re-enable upload button.
        * If success:
          - Update `#wizard-resume-status` with green checkmark: `✓ Resume parsed! Discovered ${roles.length} market roles.`
          - Hydrate `wizardRolesList` and `wizardLocationsList` with the newly parsed roles and locations so Step 2 reflects them immediately.
          - Re-render wizard role tags and location tags.
        * If error:
          - Update `#wizard-resume-status` with error notice.
    - In `goToWizardStep(stepNum)`:
      - Add guard: if `isWizardParsingResume` is true and `stepNum > 1`, prevent navigation and show toast `"Please wait for resume parsing to complete before proceeding."`.
    - In `public/js/profile.js`:
      - Dispatch `window.dispatchEvent(new CustomEvent('resume-parse-complete', { detail: { success, data, error } }))` when `/api/profile/upload-resume` finishes so the wizard listener receives the event cleanly.
  </action>
  <verify>grep -n "isWizardParsingResume" public/js/guide.js</verify>
  <done>Setup wizard disables Next button during resume parsing, shows waiting message, and re-enables Next upon completion.</done>
</task>
