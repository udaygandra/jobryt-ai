# Plan 24.2: Per-API Request Builders (Higher Yield, Preference-Accurate)

## Objective
Each board gets a dedicated `buildRequest(ctx)` that sends **only** parameters the user actually set in Settings and that the board's API actually supports, and pushes as much filtering as possible server-side so fewer irrelevant rows are fetched and more relevant pages fit in the budget.

## Context
- Settings inputs: target titles, locations, `country_scope`, `work_type`, `commute_radius_km`, `freshness_hours`, per-board toggles.
- scripts/engine/fetch-all-boards.js, new scripts/engine/board-requests.js
- User personas considered: remote-only dev, new grad, career-changer, senior IC, executive, nurse (onsite), trades, US/CA cross-border, non-technical admin, part-time/student.

## Request spec per board

| Board | Params sent (only if user set) | Yield tactics |
|-------|-------------------------------|---------------|
| Adzuna | `what` (core title, seniority words stripped), `where` (city only), `distance=radius` (km, clamp 1-100), `max_days_old=ceil(freshness/24)`, `sort_by=date`, `results_per_page=50`; omit `where`/`distance` when Remote-only; add `what_or` synonyms | Pages 1-3 concurrently; stop when page returns <50; title-synonym variants (e.g. "Data Analyst" → "BI Analyst", "Reporting Analyst") as extra tasks capped at 2 |
| LinkedIn guest | `keywords`, `location` ("City, Province, Country"), `f_TPR` mapped from freshness (r3600/r86400/r259200/r604800), `f_WT` (1 onsite, 2 remote, 3 hybrid; for "Hybrid & Remote" send two tasks `2` and `3`), `distance` (miles = km×0.621) | start=0,25,50 concurrently; drop non-target-city cards BEFORE detail fetch; detail fetch only for cards passing title+location gate |
| Canada Job Bank | `searchstring`, `locationstring` (city, province), `sort=D`, `fage` (days) | Telework filter: `fskl=...` only when remote wanted; parse telework pill |
| Indeed (scrape) | `q`, `l`, `radius` (km), `fromage` (days), `sc=0kf:attr(DSQF7)` remote only when remote-only | Only when scope matches country domain |
| USAJOBS | `Keyword`, `LocationName`, `Radius` (miles), `DatePosted` (days), `RemoteIndicator=True` only for remote-only | Skipped unless scope US/US_CA/GLOBAL |
| Remote feeds (Remotive, Jobicy, Himalayas, Arbeitnow) | Only queried when work_type includes Remote; `search`/`tag` = core title; Jobicy `geo` = country; no location radius | Local post-filter by country eligibility + title relevance |
| Country boards (Reed, Seek, Bayt, Naukri, WTTJ, Daijob, Vagas, MyCareersFuture, Arbeitsagentur) | Only when `country_scope` matches; board-native radius/date params | One task each |

Common rules: never send a param the user left blank; seniority words (Senior/Lead/Jr) are kept in LinkedIn/Indeed `keywords` but stripped for Adzuna `what` (recall) and re-scored locally; every request logs its final URL (key redacted) for debugging.
