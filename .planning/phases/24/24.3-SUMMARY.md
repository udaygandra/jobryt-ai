# Plan 24.3 Summary: Scoring Engine v2 (Location as Hard Gate)

**Status:** Complete

## Delivered
- `scripts/engine/scoring-v2.js` (new):
  - Unified 4-pillar formula: `45% Skills + 30% Seniority + 10% Function + 15% Location (Gate)`.
  - Deterministic `locationGate`:
    - Remote roles pass gate with 100% location fit score.
    - Physical/hybrid roles inside candidate commute radius pass gate with 85–100% radial gradient.
    - Physical/hybrid roles outside candidate commute radius fail gate, capped at `<= 45%` overall score, with `should_apply = false`.
  - Proximity ranking invariant: within the radius, skills and seniority dictate candidate rank rather than small differences in geographic distance.
- `prompts/job-scoring.txt`:
  - Synchronized prompt schema with Scoring v2, introducing `function_fit_score` and removing LLM hallucination of geographic commute boundaries.
- `scripts/engine/node-logic.js`:
  - Updated `runGeoFilter`, `computeHeuristicScore`, and `runParseScore` to evaluate `locationGate` and `combine` with 4-pillar weights.
- `public/js/opportunities.js`:
  - Updated UI breakdown chips to clearly render Skills (45%), Seniority (30%), Role (10%), and Loc (15% Gate).
- `tests/test-scoring-v2.test.js` (new):
  - 10 diverse persona scenarios (Full-Stack Engineer, Junior Data Analyst, VP Engineering, DevOps, Product Manager, ML Engineer, Mobile Developer, Cybersecurity Analyst, Technical Writer unstated skills, Quantitative Researcher).
