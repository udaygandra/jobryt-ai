# Plan 13.2: Google Maps-Grade Hybrid Combobox with Live Remote Suggestions & Custom City Fallback

## Objective
Elevate the Settings city combobox into a Google Maps-style hybrid search interface. Render instant top/major cities from local JSON in 0ms, query the live geocoding API with debounced fetching for any typed city, and provide a guaranteed custom city fallback so users can click or press Enter to add any municipality even if unlisted in any database.
