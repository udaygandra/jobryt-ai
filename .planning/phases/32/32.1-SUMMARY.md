# Phase 32 Plan 1: Single-Step Tailored Package Modal with Deferred Commit Summary

**Replaced the two-step application interstitial with a unified Tailored Package modal featuring synchronous Download & Submit and deferred-commit Not Ready support.**

## Accomplishments
1. **Deferred Commit Tailoring (`scripts/engine/tailor-engine.js` & `src/routes/jobs.js`)**:
   - Added `options.persist` (default `true`) to `tailorJobApplication`. When `persist === false`, artifacts (`resume.json`, `cover_letter.txt`, PDF) are cached to disk, but `jobsDb.saveAppliedJob` is bypassed.
   - Updated `POST /api/jobs/apply` to accept `commit` (default `true`), skipping job removal when `commit === false`.
   - Added `POST /api/jobs/:id/submit-tailored` to atomically move tailored opportunities to `applied_jobs` with status `Tailored` while preserving non-Tailored statuses.

2. **Tailored Package Modal (`public/index.html`)**:
   - Replaced `#applied-confirm-modal` layout with a single-step modal showing the role/company header, attached resume badge with preview link, scrollable tailored cover letter panel, and action footer.
   - Removed obsolete "Did you submit your application?" questions and "Yes, I Submitted!" buttons.

3. **Frontend Wiring (`public/js/opportunities.js` & `public/js/custom-tailor.js`)**:
   - In `applyToJob`: requests tailoring with `commit: false`, leaving the job card in place until the user commits.
   - In `showApplicationPrompt`: populates modal data, binds synchronous user gestures (new tab opening, PDF downloading, clipboard copy notification), and commits via `/api/jobs/:id/submit-tailored`.
   - Added `closePackageModal` handling for "Not Ready", ✕ close button, backdrop click, and Escape key dismissals without modifying the opportunity.
   - Updated `custom-tailor.js` to preserve committed status for custom jobs.

## Verification
- Unit test verified that `persist: false` preserves `pending_jobs` and does not insert into `applied_jobs`, while subsequent `persist: true` transitions the job to `applied_jobs` with status `Tailored`.
- HTML structure verified for all IDs (`btn-pkg-submit`, `btn-pkg-not-ready`, `pkg-modal-letter`, `pkg-modal-resume-chip`).
- All existing experience calculator and LLM state test suites pass.
