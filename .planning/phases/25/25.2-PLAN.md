# Plan 25.2: Automatic Settings Sync Engine & Profile Upload Route Integration

## Objective
Wire the parsed target titles, location, and country code from the single-prompt resume extraction directly into `settings.json` (`target_roles`, `target_locations`, `country_scope`) in `src/routes/profile.js` so uploading a resume in "My Resume and Profile" immediately sets the user's active search preferences.

## Context
- .gsd/SPEC.md
- src/routes/profile.js
- src/routes/settings.js
- scripts/core/settings-helper.js
- data/config/settings.json
- data/profiles/master-profile.json

## Tasks

<task type="auto">
  <name>Implement syncProfileRolesToSettings in settings-helper.js</name>
  <files>scripts/core/settings-helper.js</files>
  <action>
    - Add `syncProfileToSettings(profile)` in `scripts/core/settings-helper.js`:
      - Reads existing `settings.json`.
      - Extracts up to 10 unique, non-empty `target_titles` from `profile` and sets `settings.target_roles`.
      - Extracts `profile.locations` or `profile.contact.location` and updates `settings.target_locations` (capped at 5 cities).
      - If `profile.country_code` is valid and not 'GLOBAL', updates `settings.country_scope`.
      - Atomically persists the updated settings to `data/config/settings.json`.
      - Returns the updated settings object.
  </action>
  <verify>node -e "const { syncProfileToSettings } = require('./scripts/core/settings-helper'); console.log(typeof syncProfileToSettings);"</verify>
  <done>`syncProfileToSettings` updates `target_roles`, `target_locations`, and `country_scope` in `settings.json`.</done>
</task>
