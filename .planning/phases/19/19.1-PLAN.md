# Plan 19.1: Fix Recruiter Drawer Execution & Event Handling Architecture

## Objective
Fix the "Find Recruiters" button which failed to respond due to nested quotes in inline HTML `onclick` attributes. Refactor card button event handlers to pass simple IDs (`appId`) and look up job data from a robust client-side Map, ensuring 100% reliable click execution without string quote syntax collisions.

## Context
- `public/js/applied.js`
- `src/routes/recruiters.js`

## Tasks
