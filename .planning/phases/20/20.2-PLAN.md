# Plan 20.2: Eye-Friendly Warm Light Theme Palette & Visual Ergonomics Overhaul

## Objective
Address user feedback that the current light theme is "too bright" causing eye strain. Replace the harsh, stark `#FFFFFF` / cold blue-white palette with a soothing, warm-neutral, low-glare SaaS light palette (inspired by Linear, Notion, and GitHub's warm light modes) that dramatically reduces blue-spectrum luminance while preserving crisp typography and visual hierarchy.

## Context
- `public/css/theme.css`: Theme variables and light theme overrides
- `public/index.html`: Base page structure
- `public/css/style.css`: Core layout styling

## Tasks

<task type="auto">
  <name>Redesign Light Theme Color Tokens for Eye Comfort & Reduced Glare</name>
  <files>
    public/css/theme.css
  </files>
  <action>
    - In `public/css/theme.css`:
      - Re-engineer the `[data-theme="light"]` root variables:
        - `--bg-base`: Change from blinding `#F8FAFC` to soothing warm-neutral low-glare canvas `#EDEFF2` (or `#EFF1F4`).
        - `--surface-base`: Soft clean surface `#FFFFFF` with warm undertones.
        - `--surface-elevated`: Gentle off-white `#F8F9FA` for secondary surfaces.
        - `--surface-inset`: Soft warm recessed tone `#E8EBF0` for wells and search containers.
        - `--border-subtle`: Softer, less jarring border `#DDE1E6`.
        - `--border-strong`: Medium-contrast border `#C1C7D0`.
        - `--text-primary`: Shift from harsh stark black `#0F172A` to ergonomic deep charcoal `#1E232B` (reduces reading strain while maintaining high contrast).
        - `--text-muted`: Refined slate-charcoal `#5A6472`.
        - `--primary`: Refined amber-gold `#B45309` with softer warm hover `#92400E`.
        - `--card-shadow`: Softer, warmer diffused shadow `0 1px 3px 0 rgba(24, 28, 33, 0.05), 0 1px 2px -1px rgba(24, 28, 33, 0.03)`.
        - `--card-shadow-hover`: Gentle elevation `0 4px 12px -2px rgba(24, 28, 33, 0.08)`.
  </action>
  <verify>
    node -e "const fs = require('fs'); const css = fs.readFileSync('public/css/theme.css', 'utf8'); assert(css.includes('--bg-base: #EDEFF2') || css.includes('--bg-base: #EFF1F4')); console.log('✅ Light theme tokens verified');"
  </verify>
  <done>
    Root light theme variables establish a calming, low-glare visual foundation without harsh bleached backgrounds.
  </done>
</task>
