# Plan 20.1: Theme-Aware Toast Notification Engine & Text Inversion Fix

## Objective
Fix the floating toast notification which was completely invisible in light theme due to black text overriding on a dark background (`[data-theme="light"] .text-slate-100 { color: #0F172A !important; }` inside `bg-slate-900/95`). Re-architect the toast system with dedicated theme-responsive CSS classes, semantic status icons (success, error, warning, info), and resilient text styling that looks striking and legible in both light and dark modes.

## Context
- `public/js/utils.js`: `showToast()` function
- `public/css/theme.css`: Toast component styles & theme overrides
- `public/index.html`: `#toast-container`
