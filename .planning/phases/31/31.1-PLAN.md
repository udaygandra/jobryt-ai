# Plan 31.1: Multi-Board Ingestion Debottlenecking (LinkedIn 25-Step Pagination, Canada Job Bank Multi-Page, Robust Fallbacks)

## Objective
Overhaul the board ingestion adapters to eliminate the volume disparity between Adzuna (which pulls 180+ listings) and other tier-1 boards. Expand LinkedIn Guest API to fetch up to 75-100 listings using LinkedIn's native 25-item pagination step (`start = 0, 25, 50, 75`), paginate Canada Job Bank across pages 1 to 3, and improve request resilience across regional feeds without hanging or throttling.

## Context
- `scripts/engine/fetch-all-boards.js`
- `scripts/engine/board-requests.js`
- `scripts/engine/fetch-pool.js`

  <files>scripts/engine/fetch-all-boards.js, scripts/engine/fetch-pool.js</files>
  <action>
    - In `scripts/engine/fetch-all-boards.js` inside `fetchLinkedIn()`:
      1. Fix the pagination loop from `page <= 1` with `start = page * 10` to paginate across 3 pages (or 4 if count permits) using LinkedIn's native 25-result batch step:

    - In `scripts/engine/fetch-pool.js`:
      - Verify LinkedIn rate limiting allows smooth concurrent pacing (e.g. max: 3, gapMs: 100) to maximize yield while staying under rate limit triggers.
  </action>
