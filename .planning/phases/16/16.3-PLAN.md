# Plan 16.3: Responsive Fluid Navigation, Overflow Guardrails & Chrome Tab Favicon Match

## Objective
Ensure the top navigation bar and all view containers fluidly adjust to any screen size and viewport resize so that "Run Scan" and primary actions are never pushed out of the UI container. Make the menu logo badge slightly larger and update the browser tab favicon to match the official JobRyt logo.

- `public/index.html`
- `public/css/style.css`
- `public/favicon.svg`
- `.gsd/ROADMAP.md`
